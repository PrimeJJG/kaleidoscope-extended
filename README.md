# Kaleidoscope Extended: A Toy C++ Compiler & LLVM Sandbox

An extended implementation of the [LLVM Kaleidoscope Tutorial](https://llvm.org/docs/tutorial/MyFirstLanguageFrontend/index.html), built to explore frontend compiler design (lexing, parsing, AST generation) and LLVM internals (IR generation, optimization passes, and JIT compilation).

---

## 🚀 Features & Extensions

In addition to the core Kaleidoscope feature set, this implementation includes:

- **[Planned] Comments:** Support for C-style single-line comments (`//`).
- **[Planned] Extended Arithmetic:** Support for modulo (`%`) and exponentiation (`^`) with right-associativity.
